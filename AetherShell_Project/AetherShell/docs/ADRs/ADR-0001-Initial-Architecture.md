# ADR-0001: Initial Architecture Choices

## Status
Accepted

## Context
Greenfield AI-first shell.

## Decision
Adopt Clean Architecture with Semantic Kernel central orchestration.
Use WinUI 3 for UI.
SQLite for persistence.

## Rationale
Maintainability, extensibility, Microsoft first-party support.

## Consequences
Positive: Strong ecosystem.
Negative: Learning curve for shell integration.

Approved by: CSA
